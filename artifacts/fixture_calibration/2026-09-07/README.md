# Fixture Calibration v1

As of: 2026-09-07

This shadow-only layer shrinks the current league home-xG ratio and draw frequency toward strong neutral priors. It identifies draw-risk zones and waits for five home plus five away observations before a team-specific venue effect can activate. It does not change Player Alpha, the 60/30/10 base, contextual coefficients, frozen predictions, or capital authorization.
